ÜNİTE 01

İnternet Temel Kavramları, Protokoller ve Ağ Mimarisi

İnternet; TCP/IP protokol takımı üzerinden iletişim kuran, dünya genelindeki bilgisayar ağlarının birbirine bağlandığı küresel bir ağlar ağıdır (Network of Networks). 1969'da ABD Savunma Bakanlığı ARPA birimi tarafından kurulan ARPANET ile başlamıştır.

1.1. TCP/IP Protokol Yığını Katmanları

Katman Adı İşlevi Protokoller
Uygulama (Application) Kullanıcı programları ile iletişim sağlar. HTTP, HTTPS, FTP (Dosya aktarımı), SMTP (E-posta gönderme), POP3/IMAP, DNS, Telnet, SSH.
Taşıma (Transport) Uçtan uca güvenilir veya hızlı veri aktarımı. TCP (Bağlantı odaklı, 3'lü el sıkışma / 3-way handshake, güvenilir), UDP (Bağlantısız, hızlı, kayıplara toleranslı).
İnternet (Internet / Network) Mantıksal adresleme ve paket yönlendirme. IP (IPv4, IPv6), ICMP (Ping), ARP (IP → MAC eşleme).
Ağ Erişimi (Network Access) Donanım, fiziksel iletim ve çerçeveleme. Ethernet, Wi-Fi (802.11), Fiber Optik.

1.2. İstemci - Sunucu (Client-Server) ve DNS Mimarisi

İstemci (Client)
Web tarayıcısı (Chrome, Firefox) üzerinden sunucudan bir web sayfası talep eden (Request) kullanıcı bilgisayarıdır.
Sunucu (Server)
Gelen talebi dinleyen, işleyen ve istenen HTML/CSS/JS kaynağını yanıt (Response) olarak geri gönderen güçlü ana bilgisayardır (Apache, Nginx, IIS).
DNS (Domain Name System)
İnsanların hatırlaması kolay alan adlarını (örn: istanbul.edu.tr) bilgisayarların anlayacağı sayısal IP adreslerine (örn: 194.27.128.10) çeviren internetin telefon rehberidir.

ÜNİTE 02

Web Teknolojileri, İstemci/Sunucu Dilleri ve HTTP Durum Kodları

Web teknolojileri; sayfaların statik belgelerden (Web 1.0), kullanıcı etkileşimli sosyal platformlara (Web 2.0) ve anlamsal yapay zeka destekli web ortamına (Web 3.0) evrilmesiyle gelişmiştir.

2.1. İstemci Taraflı vs Sunucu Taraflı Programlama

Kriter İstemci Taraflı (Client-Side) Sunucu Taraflı (Server-Side)
Çalıştığı Yer Kullanıcının kendi tarayıcısında (Browser) çalışır. Uzak web sunucusunda (Web Server) çalışır.
Diller HTML, CSS, JavaScript. PHP, ASP.NET (C#), Python (Django/Flask), Node.js, Java.
Kod Görünürlüğü Kaynak kodları kullanıcı tarafından "Kaynağı Görüntüle" ile tamamen okunabilir. Kullanıcı sunucu kodunu göremez; sunucu kodu derleyip tarayıcıya yalnızca saf HTML çıktısı gönderir.
Veritabanı Erişimi Güvenlik nedeniyle doğrudan veritabanına bağlanamaz. Veritabanına (MySQL, Oracle) güvenli olarak doğrudan bağlanır ve sorgular yapar.

2.2. En Çok Çıkan HTTP Durum Kodları (Status Codes)

⚠️ Sınavlarda En Çok Sorulan HTTP Durum Kodları:

  • 200 OK: İstek başarıyla gerçekleşti ve içerik gönderildi.
  • 301 Moved Permanently: İstenen sayfa kalıcı olarak yeni bir URL'ye taşındı (Yönlendirme).
  • 400 Bad Request: İstemci tarafından gönderilen istek geçersiz veya bozuk.
  • 401 Unauthorized: Kimlik doğrulama gerekli (Giriş yapılmamış).
  • 403 Forbidden: Sunucu isteği anladı ancak kullanıcının bu kaynağa erişim yetkisi kesinlikle yok.
  • 404 Not Found: İstenen sayfa veya dosya sunucuda bulunamadı.
  • 500 Internal Server Error: Sunucunun kendi yazılımında/kodunda beklenmedik bir hata oluştu.

ÜNİTE 03

Web Tarayıcı Çalışma Mantığı ve DOM (Belge Nesne Modeli) İnşası

Tarayıcı (Browser); sunucudan gelen HTML, CSS ve JavaScript kodlarını çözümleyip kullanıcıya görsel ve etkileşimli bir web sayfası olarak sunan karmaşık bir yazılımdır.

3.1. Tarayıcının Sayfayı Ekrana Çizme Adımları (Critical Rendering Path)

  1. 1. HTML Parsing ve DOM Ağacı İnşası: Tarayıcı HTML etiketlerini bayt → karakter → belirteç (token) → düğüm (node) hiyerarşisine dönüştürerek DOM (Document Object Model) ağacını kurar.
  2. 2. CSS Parsing ve CSSOM Ağacı İnşası: CSS kuralları taranarak stilleri hiyerarşik tutan CSSOM (CSS Object Model) ağacı oluşturulur.
  3. 3. Render Ağacı (Render Tree): DOM ile CSSOM birleştirilir. Ekranda görünmeyecek öğeler (display: none veya <head>) elenir.
  4. 4. Düzen / Yerleşim (Layout / Reflow): Her bir elemanın ekrandaki tam piksel koordinatları ve boyutları hesaplanır.
  5. 5. Boyama / Çizim (Painting): Piksel piksel renkler, metinler, kenarlıklar ve görseller ekran tamponuna (framebuffer) çizilir.

HTML (HyperText Markup Language); web sayfalarının iskeletini ve mantıksal içeriğini tanımlayan standart işaretleme dilidir. Bir programlama dili değil, etiketleme (markup) dilidir.

4.1. Standart HTML5 Belge İskeleti

<!DOCTYPE html>
<html lang="tr">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Sayfa Başlığı</title>
  </head>
  <body>
    <h1>Ana Başlık</h1>
    <p>Bu bir paragraf metnidir. <strong>Kalın</strong> ve <em>vurgulu</em>.</p>
  </body>
</html>

4.2. HTML5 Semantik (Anlamsal) Etiketleri

Etiket Semantik Anlamı ve Görevi
<header> Sayfanın veya bir bölümün başlık alanı (Logo, site adı, arama kutusu).
<nav> Sitenin ana dolaşım / menü bağlantılarını barındıran bölüm.
<main> Sayfanın en temel, benzersiz ana içerik alanı (Sayfada sadece 1 adet bulunmalıdır).
<article> Kendi başına anlam ifade eden bağımsız içerik (Blog yazısı, haber makalesi).
<section> Tematik olarak birbirine bağlı içerik grubu veya bölümü.
<aside> Ana içerikle dolaylı ilişkili yan panel, kenar çubuğu (Sidebar) veya reklamlar.
<footer> Sayfanın en altındaki telif hakkı, iletişim ve yasal linkler alanı.

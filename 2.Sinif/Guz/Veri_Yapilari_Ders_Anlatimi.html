ÜNİTE 01

Veri Yapılarına Giriş, Algoritma Analizi ve Asimptotik Notasyon (Big-O)

Veri yapıları; verilerin bilgisayar belleğinde (RAM) verimli bir şekilde organize edilmesi, depolanması ve işlenmesi için kullanılan mantıksal yapılardır. Algoritma analizi ise bir algoritmanın girdi boyutu (n) büyüdükçe ihtiyaç duyduğu zaman ve bellek miktarını ölçer.

1.1. Asimptotik Notasyonlar (Big-O, Omega, Teta)

Notasyon Anlamı ve Sınırı Kullanım Amacı
Big-O (O) Üst Sınır (Worst-Case): Algoritmanın en kötü durumda çalışacağı maksimum süreyi garanti eder. Endüstride ve sınavlarda standart olarak en kötü durum analizi için kullanılır.
Omega (Ω) Alt Sınır (Best-Case): Algoritmanın en iyi durumda çalışacağı minimum süreyi gösterir. Algoritmanın en hızlı ne kadar çalışabileceğini belirtir.
Teta (Θ) Tam Sıkı Sınır (Tight Bound): Algoritmanın hem alt hem üst sınırının aynı büyüme derecesine sahip olduğunu gösterir. En kesin karmaşıklık ifadesidir.

1.2. Zaman Karmaşıklığı Büyüme Sıralaması

O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)

  • O(1) - Sabit Zaman: Diziye indeksle doğrudan erişim (örn. arr[5]).
  • O(log n) - Logaritmik: İkili arama (Binary Search), her adımda arama uzayını yarıya indirme.
  • O(n) - Doğrusal: Tek döngü, dizide baştan sona eleman arama (Doğrusal Arama).
  • O(n²) - Karesel: İç içe iki döngü (Bubble Sort, Selection Sort).

1.3. C Dilinde Dinamik Bellek Yönetimi Fonksiyonları

Veri yapılarında düğümler (nodes) dinamik olarak Heap bellekte açılır:

  • malloc(size): İstenen bayt kadar bellek ayırır, içini sıfırlamaz (çöp değer kalır).
  • calloc(num, size): Bellek ayırır ve tüm bitleri sıfıra (0) eşitler.
  • realloc(ptr, new_size): Ayrılmış bellek bloğunun boyutunu genişletir/daraltır.
  • free(ptr): Heap bellekte ayrılan alanı sisteme iade eder. Unutulursa Bellek Sızıntısı (Memory Leak) oluşur!

ÜNİTE 02

Tek Yönlü Bağlı Listeler (Singly Linked List)

Bağlı liste; bellekte ardışık (yan yana) yer tutma zorunluluğu olmayan, her biri bir veri ve bir sonraki düğümün adresini tutan işaretçiden (pointer) oluşan dinamik veri yapısıdır.

2.1. Dizi (Array) ile Bağlı Liste (Linked List) Karşılaştırması

Ölçüt Dizi (Array) Bağlı Liste (Linked List)
Bellek Tahsisi Statik (boyut önceden belirlenir) veya ardışık bellek gerektirir. Dinamiktir; çalışma anında ihtiyaç duyuldukça parça parça Heap'ten ayrılır.
Elemana Erişim İndeksle O(1) anında doğrudan erişim. Ardışık (Sequential) erişim; k. elemana ulaşmak için baştan taranır: O(n).
Araya Eleman Ekleme/Silme Zor ve yavaştır; elemanların sağa/sola kaydırılması gerekir: O(n). Çok kolay ve hızlıdır; sadece işaretçiler yönlendirilir: O(1).
Bellek İsrafı Dizi dolmasa bile ayrılan alan işgal edilir. Sadece kullanılan eleman kadar yer tutar ancak her düğümde ekstra pointer alanı harcanır.

2.2. Düğüm (Node) Yapısının C Kodunda Tanımlanması

#include <stdio.h>
#include <stdlib.h>

// Tek yönlü bağlı liste düğüm yapısı
struct Dugum {
    int veri;              // Düğümde saklanan değer
    struct Dugum* sonraki; // Bir sonraki düğümün adresini tutan işaretçi (pointer)
};

int main() {
    // 1. Düğümü Heap bellekte oluştur
    struct Dugum* ilk = (struct Dugum*)malloc(sizeof(struct Dugum));
    ilk->veri = 10;
    ilk->sonraki = NULL;

    printf("Olusturulan Dugum Verisi: %d\n", ilk->veri);
    free(ilk); // Belleği serbest bırak
    return 0;
}

Kodun Satır Satır Açıklaması:

  • struct Dugum* sonraki;: Kendi türünden bir yapının adresini tutan özyinelemeli (self-referential) işaretçidir.
  • malloc(sizeof(struct Dugum));: Heap bellekten bir düğüm boyutu kadar (genellikle 4 bayt int + 8 bayt pointer = 12-16 bayt) yer tahsis eder.
  • ilk->veri = 10;: İşaret edilen düğümün veri alanına 10 değerini yazar.
  • ilk->sonraki = NULL;: Listenin sonunu belirtmek üzere sonraki göstericiyi boş (NULL) yapar.

Konsol Çıktısı:

Olusturulan Dugum Verisi: 10

ÜNİTE 03

Tek Yönlü Bağlı Listelerde Ekleme, Silme ve Arama İşlemleri

Bağlı listelerde listenin başına, sonuna veya arasına eleman ekleme ve silme işlemleri işaretçilerin doğru sırada yeniden bağlanmasıyla gerçekleştirilir.

3.1. Başa Ekleme (Prepend) ve Sona Ekleme (Append)

// Listenin basina eleman ekleme fonksiyonu - Zaman Karmaşıklığı: O(1)
void basaEkle(struct Dugum** basRef, int yeniVeri) {
    struct Dugum* yeniDugum = (struct Dugum*)malloc(sizeof(struct Dugum));
    yeniDugum->veri = yeniVeri;
    yeniDugum->sonraki = (*basRef); // Yeni düğüm eski başı göstersin
    (*basRef) = yeniDugum;          // Baş işaretçisi artık yeni düğümdür
}

⚠️ Sınav Çeldiricisi: Başa Eklemede İşaretçi Sıralaması Hatası

Eğer önce (*basRef) = yeniDugum; yapılır, sonra yeniDugum->sonraki = (*basRef); denirse; listenin eski elemanlarının tamamına erişim kopar ve liste sonsuz döngüye girer! Önce yeni düğüm eski başa bağlanmalı, ardından baş güncellenmelidir.

ÜNİTE 04

Çift Yönlü Bağlı Listeler (Doubly Linked List)

Çift yönlü bağlı listelerde her düğüm hem kendisinden bir sonraki düğümün adresini (next) hem de kendisinden bir önceki düğümün adresini (prev) saklar. Bu sayede liste üzerinde her iki yönde de çift taraflı gezinmek mümkündür.

4.1. Çift Yönlü Düğüm Yapısı

struct CiftDugum {
    int veri;
    struct CiftDugum* sonraki; // Next pointer
    struct CiftDugum* onceki;  // Previous pointer
};
  • Avantajı: Bir düğüm bilindiğinde önceki düğüme tek adımda O(1) sürede ulaşılabilir; sondan başa doğru gezinilebilir.

ÜNİTE 08

Yığın (Stack) Veri Yapısı ve LIFO Prensibi

Yığın (Stack); eleman ekleme ve çıkarma işlemlerinin yalnızca tek bir uçtan (Tepe / Top) yapıldığı, Son Giren İlk Çıkar (LIFO - Last In First Out) mantığıyla çalışan doğrusal veri yapısıdır.

8.1. Temel Yığın Operasyonları ve C Kodu

  • push(x): Yığının tepesine yeni bir eleman ekler: O(1).
  • pop(): Yığının tepesindeki elemanı çıkarır ve değerini döndürür: O(1).
  • peek() / top(): Tepedeki elemanı çıkarmadan sadece okur: O(1).
  • isEmpty(): Yığının boş olup olmadığını kontrol eder.
#define BOYUT 5
int yigin[BOYUT];
int tepe = -1; // Yığın başlangıçta boş

void push(int deger) {
    if (tepe == BOYUT - 1) {
        printf("Hata: Yigin Dolu (Stack Overflow)!\n");
        return;
    }
    tepe++;
    yigin[tepe] = deger;
}

int pop() {
    if (tepe == -1) {
        printf("Hata: Yigin Bos (Stack Underflow)!\n");

    }
    int cikan = yigin[tepe];
    tepe--;
    return cikan;
}

ÜNİTE 11

Ağaç (Tree) Veri Yapısı, Terminolojisi ve İkili Ağaçlar (Binary Tree)

Ağaç (Tree); hiyerarşik ilişkileri modelleyen, doğrusal olmayan (non-linear) bir veri yapısıdır. Bir kök (root) düğüm ile başlar ve her düğüm sıfır veya daha fazla alt düğüme (çocuk) bağlanır. Çevrim (cycle) içermez.

11.1. Ağaç Terminolojisi ve Kavram Sözlüğü

Kök (Root)
Ağacın en tepesindeki düğümdür. Üst ebeveyni (parent) bulunmayan tek düğümdür.
Düğüm (Node)
Veriyi ve alt dallara giden bağlantıları (pointer) barındıran temel veri elemanıdır.
Ebeveyn (Parent) ve Çocuk (Child)
Bir düğüme doğrudan bağlı olan alt düğümlere çocuk, üstteki düğüme ise ebeveyn denir.
Yaprak (Leaf / Terminal Node)
Hiçbir alt çocuğu olmayan düğümlerdir (sol ve sağ göstericileri NULL'dur).
Kardeş (Sibling)
Aynı ebeveyne (parent) bağlı olan çocuk düğümlerdir.
Derinlik (Depth)
Bir düğümden köke olan kenar sayısıdır. Kökün derinliği 0'dır.
Yükseklik (Height)
Bir düğümden en uzaktaki yaprağa giden en uzun yoldaki kenar sayısıdır. Yaprağın yüksekliği 0'dır. Ağacın yüksekliği kökün yüksekliğidir.
Derece (Degree)
Bir düğümün sahip olduğu çocuk sayısıdır.

11.2. İkili Ağaç (Binary Tree) Çeşitleri

Ağaç Türü Tanım ve Özellikler Matematiksel Özellik
İkili Ağaç (Binary Tree) Her düğümün en fazla 2 çocuğu (sol ve sağ çocuk) bulunabilen ağaçtır. Derece ≤ 2
Dolu İkili Ağaç (Full / Proper) Ağaçtaki her düğümün ya 0 ya da tam 2 çocuğu vardır. 1 çocuklu düğüm bulunmaz. Çocuk sayısı ∈ {0, 2}
Mükemmel İkili Ağaç (Perfect) Tüm iç düğümler 2 çocuğa sahiptir ve tüm yapraklar tamamen aynı derinlik seviyesindedir. Yükseklik h ise düğüm sayısı: 2h+1 - 1
Tam İkili Ağaç (Complete) Son seviye hariç tüm seviyeler tamamen doludur. Son seviyedeki düğümler ise en soldan sağa doğru bitişik olarak sıralanmıştır. (Dizi tabanlı Heap yapılarında zorunludur). Diziye doğrudan 2i+1 ve 2i+2 ile eşlenebilir.
Dengeli İkili Ağaç (Balanced) Herhangi bir düğümün sol ve sağ alt ağaçlarının yükseklik farkı en fazla 1'dir (AVL, Red-Black ağaçları). Yükseklik O(log n) garantilidir.

Sınavlarda "Complete Binary Tree" ile "Full Binary Tree" birbirine sıkça karıştırılır. Full Tree'de düğümün 1 çocuğu olamaz (ya 0 ya 2). Complete Tree'de ise tüm seviyeler doludur, son seviye soldan sağa dizilmelidir (yaprakların hepsi aynı hizada olmak zorunda değildir).

ÜNİTE 12

İkili Arama Ağacı (BST) ve Ağaç Dolaşma Yöntemleri (Traversals)

İkili Arama Ağacı (Binary Search Tree - BST); ikili ağaç mantığını sıralama kuralıyla birleştiren yapıdır: Bir düğümün sol alt ağacındaki tüm elemanlar o düğümden KÜÇÜK, sağ alt ağacındaki tüm elemanlar o düğümden BÜYÜK olmak zorundadır.

12.1. Ağaç Dolaşma Yöntemleri (Tree Traversals)

Ağaçtaki tüm düğümleri tek tek ziyaret etmenin 4 temel yöntemi vardır:

Dolaşma Yöntemi Ziyaret Sırası (Algoritma) Önemli Özelliği ve Kullanım Alanı
In-order (İçten/Ortadan) 1. Sol Alt Ağaç → 2. Kök (Root) → 3. Sağ Alt Ağaç ÇOK ÖNEMLİ: İkili Arama Ağacında (BST) In-order dolaşma, elemanları küçükten büyüğe sıralı (ascending) olarak listeler!
Pre-order (Önden/Kökten) 1. Kök (Root) → 2. Sol Alt Ağaç → 3. Sağ Alt Ağaç Ağacın tam bir kopyasını oluşturmak ve matematiksel önek (prefix) ifadeleri üretmek için kullanılır.
Post-order (Sondan) 1. Sol Alt Ağaç → 2. Sağ Alt Ağaç → 3. Kök (Root) Ağacı bellekten temizlerken (free) ve alt düğümler silinmeden kökü silmemek gerektiğinde kullanılır. Sonsöz (postfix) ifadeler üretir.
Level-order (Seviye Bazlı) Kökten başlayarak derinlik seviyelerine göre soldan sağa gezer. Kuyruk (Queue) veri yapısı kullanılarak BFS (Breadth-First Search) mantığıyla çalışır.

12.2. BST Dolaşma Algoritmaları C Kodu

// In-order Gezinme (Sol -> Kök -> Sağ)
void inOrder(struct AgacDugumu* kok) {
    if (kok != NULL) {
        inOrder(kok->sol);
        printf("%d ", kok->veri);
        inOrder(kok->sag);
    }
}

// Pre-order Gezinme (Kök -> Sol -> Sağ)
void preOrder(struct AgacDugumu* kok) {
    if (kok != NULL) {
        printf("%d ", kok->veri);
        preOrder(kok->sol);
        preOrder(kok->sag);
    }
}

// Post-order Gezinme (Sol -> Sağ -> Kök)
void postOrder(struct AgacDugumu* kok) {
    if (kok != NULL) {
        postOrder(kok->sol);
        postOrder(kok->sag);
        printf("%d ", kok->veri);
    }
}

12.3. BST Eleman Silme (Deletion) Kuralları

  • Durum 1 (Yaprak Düğüm): Düğüm doğrudan silinir ve ebeveynin ilgili göstericisi NULL yapılır.
  • Durum 2 (Tek Çocuklu Düğüm): Silinen düğümün yerine tek çocuğu bağlanır (atlama yapılır).
  • Durum 3 (İki Çocuklu Düğüm): Silinen düğümün yerine ya sağ alt ağacın en küçük elemanı (In-order Successor) ya da sol alt ağacın en büyük elemanı (In-order Predecessor) getirilir.

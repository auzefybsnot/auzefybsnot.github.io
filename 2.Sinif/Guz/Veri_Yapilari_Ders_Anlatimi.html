1. Ünite: Veri Yapılarına Giriş, C++ Ortamı, Bellek ve Algoritma Analizi

Ünitenin Amacı: Veri (data), enformasyon (information) ve bilgi (knowledge) kavramlarını ayırt etmek; temel, bileşik ve soyut veri tiplerini tanımak; C++ derleme ortamını (MinGW, GCC, Visual Studio), statik ve dinamik bellek yönetimini (Stack vs. Heap, işaretçiler, new/delete, sizeof, tür dönüşümleri) ve algoritma karmaşıklığını (Big-O, $\Omega$, $\Theta$) eksiksiz kavramaktır.

1.1. Temel Kavramlar: Veri, Enformasyon ve Bilgi

Bilgisayar bilimlerinde verinin anlamlı hâle gelmesi üç aşamalı bir Bilgi Edinim Piramidi (alt katmandan üste: Veri → Enformasyon → Bilgi) ile açıklanır:

  • Veri (Data): Herhangi bir gözlem, ölçüm, olay veya işlem sonucunda elde edilen ham ve işlenmemiş gerçeklerdir. Tek başına anlam ifade etmez. (Örnek: 85, 90, 78 sınav puanları, market barkodları, ham sıcaklık ölçümleri.)
  • Enformasyon (Information): Verinin belirli bir bağlam içinde düzenlenmiş, özetlenmiş ve anlamlandırılmış hâlidir. Karar verme süreçlerinde kullanılır. (Örnek: "Sınav ortalaması: 84,3" veya "Dünkü ortalama oda sıcaklığı 22,6 °C idi.")
  • Bilgi (Knowledge): Enformasyonun deneyim, yorum ve kurallarla harmanlanarak eyleme dönüştürülebilen çıktısıdır. Stratejik kararlar ve problem çözme için kullanılır. (Örnek: "Sınav ortalaması 85'in üzerindeyse ek destek gerekmez.")

Veri Yapısı (Data Structure) Nedir?

Veri yapıları, verilerin bilgisayar belleğinde (RAM) düzenli, verimli ve anlamlı biçimde saklanmasını, yönetilmesini ve erişilmesini sağlayan özel organizasyonlardır. Niklaus Wirth'in özlü ifadesiyle: Algoritmalar + Veri Yapıları = Programlar. Doğru veri yapısı seçimi sayesinde verilere hızlı erişilir, arama/ekleme/silme/güncelleme işlemleri kolaylaşır ve bellek kullanımı optimize edilir.

1.2. C++ Programlama Dili, Derleme Süreci ve Temel Girdi/Çıktı

C++ derleyicisi, yazılan C++ kaynak kodunu (.cpp) bilgisayarın doğrudan çalıştırabileceği makine diline çevirir. Yaygın derleyici ve IDE'ler: GCC (Linux/macOS), MinGW (Windows için GCC tabanlı), Microsoft Visual Studio, Code::Blocks ve CLion.

Komut satırından MinGW/GCC ile derleme ve çalıştırma adımları:

g++ hello.cpp -o hello.exe
./hello.exe   // veya Windows'ta: hello.exe

C++ dilinde kullanıcıdan veri almak için cin >>, ekrana çıktı yazmak için cout << (C dilinde sırasıyla scanf() ve printf(), başlık dosyası <stdio.h>) kullanılır. Yeni satır için \n veya endl, sekme için \t, ses için \a, geri silme için \b kontrol karakterleri; yorum satırları için // (tek satır) veya /* ... */ (çok satır) kullanılır.

#include <iostream>
using namespace std;

int main() {
    int yas;
    cout << "Yaşınızı giriniz: ";
    cin >> yas;
    cout << "Girdiğiniz yaş: " << yas << endl;
    return 0;
}

C. Soyut Veri Tipleri (ADT - Abstract Data Types)

Verinin bellekte fiziksel olarak nasıl saklandığını gizleyip yalnızca kurallarını ve işlemlerini (arayüzünü) tanımlayan modellerdir: Bağlı Liste (Linked List) (dinamik boyut, düğüm zinciri), Yığın (Stack) (LIFO — fonksiyon çağrıları, parantez denetimi), Kuyruk (Queue) (FIFO — yazıcı kuyruğu, görev sıralama).

D. Değişkenler, Sabitler ve Tür Dönüşümleri (Type Casting)

  • Değişken adları harf, rakam ve alt çizgi (_) içerebilir; rakamla başlayamaz, büyük/küçük harfe duyarlıdır ve int, for gibi anahtar kelimeler ad olamaz. Sabitler const anahtar kelimesiyle tanımlanır (const float PI = 3.14159f;).
  • Otomatik (Implicit) Dönüşüm: Küçükten büyüğe veri tipine geçişte derleyici otomatik yapar (int a = 10; float b = a;).
  • Açık (Explicit) Dönüşüm: Büyükten küçüğe geçişte veri kaybı olabileceği için programcı tarafından belirtilir (float c = 3.7f; int d = (int)c; → $d = 3$).

1.5. Algoritma Analizi ve Asimptotik Notasyon (Big-O)

Bir algoritmanın çalışma süresinin veya bellek kullanımının girdi büyüklüğü $n$'e bağlı olarak nasıl büyüdüğünü ölçen donanımdan bağımsız analiz yöntemidir:

  • Big-O ($O$): En kötü durum (Worst Case) üst sınırını verir.
  • Omega ($\Omega$): En iyi durum (Best Case) alt sınırını verir.
  • Teta ($\Theta$): Alt ve üst sınırın çakıştığı tam/sıkı sınırı gösterir.

2. Ünite: Tek Yönlü Bağlı Listeler (Singly Linked List)

Ünitenin Amacı: Bağlı liste kavramını, düğüm (node) ve işaretçi (pointer) mimarisini, dizilerle karşılaştırmasını, dinamik bellek yönetimini (new/delete ve bellek sızıntısı önleme) ve C++ ile tek yönlü bağlı liste oluşturma, başa/sona ekleme, silme ve dolaşma (traversal) uygulamalarını öğrenmektir.

2.1. Bağlı Liste Nedir? Avantajları ve Dezavantajları

Bağlı Liste (Linked List): Veri elemanlarının (düğüm/node) bellekte ardışık olmayan (dağınık) konumlarda saklandığı, her düğümün kendi verisinin yanında bir sonraki düğümün bellek adresini (işaretçisini) tuttuğu dinamik bir veri yapısıdır.

Temel Avantajlar: Dinamik boyutludur (çalışma anında büyüyüp küçülür), başta ve sonda ekleme/silme işaretçi güncellemesiyle $O(1)$ karmaşıklıkta yapılabilir (tail tutuluyorsa), ardışık bellek bloğu gerektirmez (fragmentasyon sorunu yoktur) ve yalnızca kullanılan elemanlar kadar bellek ayırır.
Temel Dezavantajlar: Rastgele erişim yoktur ($i$. elemana ulaşmak için baştan itibaren dolaşmak gerekir: $O(n)$), her düğümde ek işaretçi alanı (4/8 byte) harcanır, kodlaması diziye göre daha karmaşıktır ve bellek adresleri dağınık olduğu için CPU önbellek (cache) verimi düşüktür.

2.2. Düğüm (Node) Yapısı ve İşaretçi (Pointer) Kullanımı

Tek yönlü bağlı listenin her düğümü iki temel bölümden oluşur:

  • Veri (data): Saklanacak bilgi (int, string, struct vb.).
  • İşaretçi (next): Bir sonraki düğümün bellek adresi.

Listenin ilk düğümü head (baş) işaretçisiyle tutulur. Hiçbir elemanı olmayan boş listede head == nullptr (veya NULL) olur. Listenin son düğümünün next işaretçisi daima nullptr/NULL değerini gösterir.

struct Node {
    int data;    // Veri kısmı
    Node* next;  // Sonraki düğümün adresi
};

2.3. Dinamik Bellek Yönetimi ve Gerçek Hayat Kullanım Alanları

Bağlı listelerde düğümler C++'ta new operatörü (C dilinde malloc()) ile heap bellekten tahsis edilir ve işi bitince mutlaka delete (C'de free()) ile serbest bırakılır. Tahsis edilen düğümün serbest bırakılmaması bellek sızıntısına (memory leak) yol açar; uzun süre çalışan sistemlerde bellek tükenir ve program çökebilir. Modern C++'ta (C++11+) std::unique_ptr ve std::shared_ptr akıllı işaretçileriyle bu risk azaltılabilir.

2.4. C++ Uygulamaları: Oluşturma, Dolaşma (Traversal), Ekleme ve Silme

Aşağıda adım adım 3 düğümlü temel liste oluşturma, temp = temp->next ile listeyi dolaşarak yazdırma, sona ekleme, değer silme ve belleği temizleme fonksiyonları verilmiştir:

#include <iostream>
using namespace std;

struct Node {
    int data;
    Node* next;
};

// Listenin sonuna eleman ekleyen fonksiyon
void sonaEkle(Node*& head, int veri) {
    Node* yeni = new Node();
    yeni->data = veri;
    yeni->next = nullptr;
    if (head == nullptr) {
        head = yeni;
    } else {
        Node* temp = head;
        while (temp->next != nullptr) {
            temp = temp->next;
        }
        temp->next = yeni;
    }
}

// Listeyi baştan sona dolaşarak (traversal) yazdıran fonksiyon
void listeYazdir(Node* head) {
    Node* temp = head;
    while (temp != nullptr) {
        cout << temp->data << " ";
        temp = temp->next;   // Bir sonraki düğüme geçiş (traversal adımı)
    }
    cout << endl;
}

// Belirli bir değere sahip düğümü silen fonksiyon
void elemanSil(Node*& head, int silinecek) {
    Node* temp = head;
    Node* onceki = nullptr;
    while (temp != nullptr && temp->data != silinecek) {
        onceki = temp;
        temp = temp->next;
    }
    if (temp == nullptr) return;       // Eleman bulunamadı
    if (onceki == nullptr) {           // İlk düğüm siliniyor
        head = temp->next;
    } else {
        onceki->next = temp->next;
    }
    delete temp;
}

// Tüm düğümleri bellekten temizleme
void bellekTemizle(Node*& head) {
    Node* temp = head;
    while (temp != nullptr) {
        Node* sil = temp;
        temp = temp->next;
        delete sil;
    }
    head = nullptr;
}

Adım Adım İzleme (Trace): 10 → 20 → 30 → nullptr

  1. head = nullptr iken sonaEkle(head, 10) çağrılır: head 10'u gösterir.
  2. sonaEkle(head, 20): temp 10'da durur, 10->next = 20 olur.
  3. sonaEkle(head, 30): temp 10 → 20 ilerler, 20->next = 30 olur.
  4. elemanSil(head, 20): onceki = 10, temp = 20 bulunur; 10->next = 30 bağlanır ve 20 delete edilir. Liste: 10 → 30 → nullptr.
Sık Yapılan Hatalar ve Sınav Notu:
1) Null Pointer Hatası: temp == nullptr iken temp->next veya temp->data erişimi programı çökertir.
2) Çift Serbest Bırakma (Double Free): Aynı düğümü iki kez delete etmek tanımsız davranışa yol açar.
3) C vs C++: C dilinde bellek ayırma malloc(), serbest bırakma free() ile; C++'ta new ve delete ile yapılır.

3. Ünite: Tek Yönlü Bağlı Listelerde Temel İşlemler

Ünitenin Amacı: Tek yönlü bağlı listelerde baştan, sondan ve aradan eleman silme işlemlerini özel durumlarıyla (boş liste, tek elemanlı liste, baş düğüm) öğrenmek; doğrusal arama ($O(n)$) ve 3 işaretçili (prev, curr, next) yerinde tersine çevirme algoritmasını C++ kodlarıyla kavramaktır.

3.1. Eleman Silme İşlemleri (Baştan, Sondan, Aradan)

Tek yönlü bağlı listede silme işlemi düğümün konumuna göre üç durumda incelenir. Her üç durumda da bellek sızıntısını önlemek için silinen düğüm mutlaka delete ile serbest bırakılmalıdır.

1. Baştan Eleman Silme — $O(1)$

  1. Önce koruyucu kontrol yapılır: if (head == nullptr) return; (liste boşsa işlem yapılmaz).
  2. Geçici bir işaretçiyle (Node* sil = head;) mevcut baş düğüm tutulur.
  3. head bir sonraki düğüme kaydırılır: head = head->next;.
  4. Eski baş düğüm delete sil; ile serbest bırakılır.
void bastanSil(Node*& head) {
    if (head == nullptr) return; // Koruyucu kontrol: liste boş
    Node* sil = head;
    head = head->next;
    delete sil;
}

2. Sondan Eleman Silme — $O(n)$

  1. Liste boşsa (head == nullptr) çıkılır.
  2. Özel Durum (Tek Elemanlı Liste): Eğer head->next == nullptr ise delete head; head = nullptr; yapılır. (Bu kontrol unutulursa temp->next->next erişimi çöker!)
  3. Birden fazla düğüm varsa sondan bir önceki düğüme (temp->next->next != nullptr) kadar ilerlenir.
  4. Son düğüm delete temp->next; ile silinir ve temp->next = nullptr; yapılır.
void sondanSil(Node*& head) {
    if (head == nullptr) return;        // Liste boş
    if (head->next == nullptr) {        // Tek elemanlı liste özel durumu
        delete head;
        head = nullptr;
        return;
    }
    Node* temp = head;
    while (temp->next->next != nullptr) {
        temp = temp->next;
    }
    delete temp->next;
    temp->next = nullptr;
}

3. Aradan (Belirli Değerle) Eleman Silme — $O(n)$

Önce boş liste ve aranan değerin başta olma durumu (head->data == deger → bastanSil(head)) kontrol edilir. Ardından temp->next != nullptr && temp->next->data != deger döngüsüyle silinecek düğümün bir öncesine gelinir; eleman varsa temp->next = sil->next; delete sil; uygulanır.

void aradanSil(Node*& head, int deger) {
    if (head == nullptr) return;
    if (head->data == deger) {          // Silinecek eleman başta ise
        bastanSil(head);
        return;
    }
    Node* temp = head;
    while (temp->next != nullptr && temp->next->data != deger) {
        temp = temp->next;
    }
    if (temp->next == nullptr) return;  // Değer listede yok
    Node* sil = temp->next;
    temp->next = sil->next;
    delete sil;
}

3.2. Bağlı Listede Doğrusal Arama ($O(n)$)

Bağlı listelerde rastgele erişim (indisle doğrudan atlama) olmadığından arama işlemi baştan sona düğümler tek tek gezilerek yapılır. Aranan değer bulunursa düğüm adresi, bulunamazsa nullptr döndürülür.

Node* ara(Node* head, int deger) {
    Node* temp = head;
    while (temp != nullptr) {
        if (temp->data == deger)
            return temp;    // Bulundu
        temp = temp->next;
    }
    return nullptr;         // Bulunamadı
}

3.3. Bağlı Listeyi Tersine Çevirme (Reverse) — $O(n)$ Zaman, $O(1)$ Ek Bellek

Her düğümün next işaretçisi bir önceki düğümü gösterecek biçimde yön değiştirir. Bu işlemde 3 işaretçi kullanılır: prev (başlangıçta nullptr), curr (başlangıçta head) ve next (nullptr).

void tersCevir(Node*& head) {
    Node* prev = nullptr;
    Node* curr = head;
    Node* next = nullptr;
    while (curr != nullptr) {
        next = curr->next;  // 1. Sonraki adresi kaybetmemek için sakla
        curr->next = prev;  // 2. Bağlantı yönünü ters çevir
        prev = curr;        // 3. prev'i bir adım ilerlet
        curr = next;        // 4. curr'ı bir adım ilerlet
    }
    head = prev;            // Döngü bitince prev eski son (yeni baş) düğümdür!
}

İzleme Örneği (Trace): 10 → 20 → 30 → nullptr

  • Başlangıç: prev = nullptr, curr = 10
  • Adım 1: next = 20, 10->next = nullptr, prev = 10, curr = 20
  • Adım 2: next = 30, 20->next = 10, prev = 20, curr = 30
  • Adım 3: next = nullptr, 30->next = 20, prev = 30, curr = nullptr
  • Bitiş: head = prev → 30 → 20 → 10 → nullptr.

4. Ünite: Çift Yönlü Bağlı Listeler (Doubly Linked List)

Ünitenin Amacı: Her düğümde hem önceki (prev) hem sonraki (next) düğümün adresini tutan Çift Yönlü Bağlı Liste mimarisini, tek yönlü listelerden farklarını, avantaj-dezavantajlarını, kullanım alanlarını ve C++ ile oluşturma, başa/sona ekleme, ileri ve geri yazdırma işlemlerini öğrenmektir.

4.1. Çift Yönlü Bağlı Liste Nedir?

Çift Yönlü Bağlı Liste (Doubly Linked List): Her düğümün kendi verisinin yanında hem bir önceki düğümün adresini (prev) hem de bir sonraki düğümün adresini (next) tuttuğu dinamik veri yapısıdır. Bu sayede listede hem baştan sona (ileri) hem sondan başa (geri) dolaşım mümkündür.

  • prev: Bir önceki düğümü gösterir. İlk düğümün (head) prev işaretçisi varsayılan olarak nullptr (NULL)'dır.
  • data: Düğümde saklanan veri alanıdır.
  • next: Bir sonraki düğümü gösterir. Son düğümün (tail) next işaretçisi varsayılan olarak nullptr (NULL)'dır.
Tek Düğümlü Liste Durumu: Çift yönlü bağlı listede yalnızca 1 düğüm varsa, o tek düğümün hem prev hem de next işaretçisi nullptr değerini gösterir. 
struct DNode {
    int data;      // Saklanan veri
    DNode* prev;   // Önceki düğümün adresi
    DNode* next;   // Sonraki düğümün adresi
};

4.4. C++ Uygulamaları: Başa/Sona Ekleme ve İleri/Geri Yazdırma

#include <iostream>
using namespace std;

struct DNode {
    int data;
    DNode* prev;
    DNode* next;
};

// Listenin başına eleman ekleme - O(1)
void basaEkle(DNode*& head, int veri) {
    DNode* yeni = new DNode();
    yeni->data = veri;
    yeni->prev = nullptr;
    yeni->next = head;
    if (head != nullptr)
        head->prev = yeni;
    head = yeni;
}

// Listenin sonuna eleman ekleme - O(n) (tail yoksa)
void sonaEkle(DNode*& head, int veri) {
    DNode* yeni = new DNode();
    yeni->data = veri;
    yeni->next = nullptr;
    if (head == nullptr) {
        yeni->prev = nullptr;
        head = yeni;
        return;
    }
    DNode* temp = head;
    while (temp->next != nullptr)
        temp = temp->next;
    temp->next = yeni;
    yeni->prev = temp;
}

// Baştan sona yazdırma
void listeYazdir(DNode* head) {
    DNode* temp = head;
    while (temp != nullptr) {
        cout << temp->data << " ";
        temp = temp->next;
    }
    cout << endl;
}

// Sondan başa (tersten) yazdırma
void terstenYazdir(DNode* head) {
    if (head == nullptr) return;
    DNode* temp = head;
    while (temp->next != nullptr)   // Önce son düğüme git
        temp = temp->next;
    while (temp != nullptr) {       // prev ile geriye doğru dolaş
        cout << temp->data << " ";
        temp = temp->prev;
    }
    cout << endl;
}

void bellekTemizle(DNode*& head) {
    while (head != nullptr) {
        DNode* sil = head;
        head = head->next;
        delete sil;
    }
}
Sınav Notu: Çift yönlü bağlı listede terstenYazdir() fonksiyonu önce while (temp->next != nullptr) ile son düğüme ilerler, ardından temp = temp->prev ile başa kadar geri döner. Ekleme işlemlerinde liste boşken (head == nullptr) head->prev erişimi yapılmamalıdır.

5. Ünite: Çift Yönlü Bağlı Listelerde İşlemler

Ünitenin Amacı: Çift yönlü bağlı listelerde baştan, sondan ve aradan düğüm silme adımlarını, her iki yöndeki işaretçilerin (prev ve next) güvenli güncellenmesini, arama işlemini ve prev/next takasına dayalı tersine çevirme (reverse) algoritmasını öğrenmektir.

5.1. Çift Yönlü Bağlı Listeden Eleman Silme

Silme işlemlerinde listenin bütünlüğünü korumak için hem prev hem de next bağlantıları eksiksiz güncellenmeli, boş liste ve tek elemanlı liste sınır durumları kontrol edilmelidir.

1. Baştan Eleman Silme — $O(1)$

  • Liste boşsa (head == nullptr) çıkılır.
  • sil = head; tutulur ve head = head->next; yapılır.
  • Yeni head nullptr değilse head->prev = nullptr; ayarlanır, ardından delete sil; çağrılır.
void bastanSil(DNode*& head) {
    if (head == nullptr) return;
    DNode* sil = head;
    head = head->next;
    if (head != nullptr)
        head->prev = nullptr;
    delete sil;
}

2. Sondan Eleman Silme — $O(n)$ (tail tutulursa $O(1)$)

  • Liste boşsa çıkılır; tek eleman varsa (head->next == nullptr) delete head; head = nullptr; yapılır.
  • Birden fazla eleman varsa while (temp->next != nullptr) ile son düğüme gelinir.
  • temp->prev->next = nullptr; ile sondan bir önceki düğümün bağlantısı kesilir ve delete temp; ile son düğüm silinir.
void sondanSil(DNode*& head) {
    if (head == nullptr) return;
    if (head->next == nullptr) {
        delete head;
        head = nullptr;
        return;
    }
    DNode* temp = head;
    while (temp->next != nullptr)
        temp = temp->next;
    temp->prev->next = nullptr;
    delete temp;
}

3. Aradan (Belirli Değerle) Eleman Silme — $O(n)$

Aranan düğüm temp bulunduğunda, eğer baştaki düğümse (temp == head) bastanSil(head) çağrılır. Aksi durumda komşular birbirine doğrudan bağlanır:

void aradanSil(DNode*& head, int deger) {
    if (head == nullptr) return;
    DNode* temp = head;
    while (temp != nullptr && temp->data != deger)
        temp = temp->next;
    if (temp == nullptr) return;            // Değer bulunamadı
    if (temp == head) {                     // Baştaki düğüm siliniyor
        bastanSil(head);
        return;
    }
    if (temp->next != nullptr)
        temp->next->prev = temp->prev;
    if (temp->prev != nullptr)
        temp->prev->next = temp->next;
    delete temp;
}

5.2. Arama ve Listeyi Tersine Çevirme (Reverse)

Arama (ara): Baş düğümden itibaren temp->next ile ilerlenir; bulunursa düğümün adresi, bulunamazsa nullptr döner ($O(n)$).

Tersine Çevirme (tersCevir): Çift yönlü bağlı listeyi tersine çevirmek için her düğümdeki prev ve next işaretçileri birbiriyle takas (swap) edilir! Dikkat: Takastan sonra bir sonraki düğüme geçmek için artık curr = curr->prev (eski next) kullanılır. Döngü sonunda head = temp->prev (eski son düğüm) olarak güncellenir.

DNode* ara(DNode* head, int deger) {
    DNode* temp = head;
    while (temp != nullptr) {
        if (temp->data == deger) return temp;
        temp = temp->next;
    }
    return nullptr;
}

void tersCevir(DNode*& head) {
    DNode* temp = nullptr;
    DNode* curr = head;
    while (curr != nullptr) {
        temp = curr->prev;
        curr->prev = curr->next;
        curr->next = temp;
        curr = curr->prev;  // prev ile next takas edildiği için ileri hareket prev'dedir
    }
    if (temp != nullptr)
        head = temp->prev;  // Eski son düğüm yeni head olur
}

6. Ünite: Dairesel Bağlı Listeler (Circular Linked List)

Ünitenin Amacı: Son düğümün next işaretçisinin nullptr yerine yeniden baş düğümü (head) gösterdiği Dairesel Bağlı Liste mimarisini, Round-Robin zamanlama ve tampon (buffer) gibi gerçek hayat uygulamalarını, tek/çift yönlü listelerle farklarını ve sonsuz döngüyü önleyen do-while C++ implementasyonunu öğrenmektir.

6.1. Dairesel Bağlı Liste Nedir? Yapısı ve Bağlantı Mantığı

Dairesel Bağlı Liste (Circular Linked List): Listenin son düğümünün next işaretçisinin nullptr yerine tekrar listenin başındaki düğümü (head) göstermesiyle oluşan döngüsel bir veri yapısıdır. Bu sayede listenin herhangi bir düğümünden başlanarak tüm elemanlar kesintisiz biçimde dolaşılabilir.

  • Dolu bir dairesel bağlı listede hiçbir düğümün next işaretçisi nullptr değildir.
  • Listedeki tek bir düğüm varsa, o düğümün next işaretçisi kendisini gösterir: yeni->next = head;.
  • Çift Yönlü Dairesel Bağlı Listede ise ek olarak ilk düğümün prev'i son düğümü, son düğümün next'i ise ilk düğümü gösterir.
struct CNode {
    int data;      // Saklanan veri
    CNode* next;   // Sonraki düğümün adresi (son düğümde head'i gösterir)
};

6.2. Avantajları, Dezavantajları ve Kullanım Alanları

  • Avantajları: Döngüsel ve kesintisiz dolaşım (sona gelince otomatik başa dönüş), herhangi bir düğümden başlayarak tüm listeyi gezebilme, Round-Robin algoritmaları ve sabit boyutlu dairesel tampon (buffer) yönetimi için ideal yapı.
  • Dezavantajları: Son düğümün head kontrolü nedeniyle kod karmaşıklığı artar, yanlış döngü koşulunda sonsuz döngü riski oluşur ve baş/son düğüm belirlenmesi ekstra özen gerektirir.

6.3. C++ Uygulaması: Ekleme, do-while ile Yazdırma ve Bellek Temizliği

#include <iostream>
using namespace std;

struct CNode {
    int data;
    CNode* next;
};

// Dairesel bağlı listenin sonuna eleman ekleme
void sonaEkle(CNode*& head, int veri) {
    CNode* yeni = new CNode();
    yeni->data = veri;
    if (head == nullptr) {          // Liste boşsa özel durum
        head = yeni;
        yeni->next = head;          // Kendini gösterir
        return;
    }
    CNode* temp = head;
    while (temp->next != head)      // Son düğümü bul
        temp = temp->next;
    temp->next = yeni;
    yeni->next = head;              // Yeni son düğüm başa bağlanır
}

// Dairesel bağlı listeyi yazdırma (do-while ile sonsuz döngü önlenir)
void listeYazdir(CNode* head) {
    if (head == nullptr) {
        cout << "Liste bos." << endl;
        return;
    }
    CNode* temp = head;
    do {
        cout << temp->data << " ";
        temp = temp->next;
    } while (temp != head);         // Başa dönüldüğünde dur!
    cout << endl;
}

// Tüm düğümleri bellekten temizleme
void bellekTemizle(CNode*& head) {
    if (head == nullptr) return;
    CNode* temp = head->next;
    while (temp != head) {
        CNode* sil = temp;
        temp = temp->next;
        delete sil;
    }
    delete head;
    head = nullptr;
}
Kritik Sınav Uyarısı (Sonsuz Döngü): Dairesel bağlı listede while (temp != nullptr) yazmak programı sonsuz döngüye sokar! Yazdırma ve arama işlemlerinde ilk düğümü atlamadan durabilmek için do { ... } while (temp != head); yapısı (öncesinde if (head == nullptr) kontrolüyle) kullanılmalıdır.

7. Ünite: Dizi Veri Yapısı (Arrays) ve Bellek Modeli

Ünitenin Amacı: Aynı türden verileri bellekte ardışık olarak saklayan Dizi (Array) yapısını, $O(1)$ rastgele erişim sağlayan adres hesaplama formülünü, statik ve dinamik dizileri (new[]/delete[], std::vector), çok boyutlu matrisleri ve diziler üzerinde Doğrusal/İkili Arama ile temel sıralama algoritmalarını öğrenmektir.

7.1. Dizi Tanımı, Bellek Modeli ve Adres Formülü

Dizi (Array): Aynı türden verilerin bilgisayar belleğinde kesintisiz ve ardışık (contiguous) adreslerde saklandığı doğrusal veri yapısıdır. İndeksleme 0'dan başlar ve son eleman boyut - 1 indeksindedir.

Doğrudan Erişim (Random Access) Adres Formülü: $$\text{Adres}(A[i]) = \text{Başlangıç Adresi (Base)} + (i \times \text{Eleman Boyutu (Byte)})$$

Bu formül sayesinde $i$. elemanın bellek adresi tek bir aritmetik işlemle hesaplanır; bu nedenle dizilerde herhangi bir elemana doğrudan erişim daima $O(1)$ sabit zaman alır.

  • Avantajları: $O(1)$ rastgele erişim, basit tanımlama ve kullanım, ardışık bellek yerleşimi sayesinde yüksek CPU önbellek (cache) verimi, ek işaretçi maliyeti (overhead) olmaması.
  • Dezavantajları: Statik dizilerde sabit boyut, ortadan ekleme ve silmede eleman kaydırma nedeniyle $O(n)$ maliyet, gereğinden büyük tanımlanırsa bellek israfı, yalnızca aynı türden veri saklama kısıtı.

7.3. Dizilerde Arama (Linear & Binary Search) ve Sıralamaya Giriş

Doğrusal Arama (Linear Search): Sıralı veya sırasız dizilerde elemanları baştan sona kontrol eder; zaman karmaşıklığı $O(n)$'dir.
İkili Arama (Binary Search): Yalnızca sıralı dizilerde çalışır; her adımda ortadaki elemanla karşılaştırma yaparak arama uzayını yarıya indirir ve $O(\log n)$ zamanda sonuca ulaşır.

int linearSearch(int dizi[], int n, int aranan) {
    for (int i = 0; i < n; i++)
        if (dizi[i] == aranan) return i;
    return -1;
}

int binarySearch(int dizi[], int n, int aranan) {
    int sol = 0, sag = n - 1;
    while (sol <= sag) {
        int orta = (sol + sag) / 2;
        if (dizi[orta] == aranan) return orta;
        else if (dizi[orta] < aranan) sol = orta + 1;
        else sag = orta - 1;
    }
    return -1;
}

8. Ünite: Yığın Veri Yapısı (Stack - LIFO)

Ünitenin Amacı: Yalnızca tek uçtan (tepe/top) ekleme ve çıkarma yapılan Son Giren İlk Çıkar (LIFO) prensipli Yığın (Stack) veri yapısını, temel işlemlerini (push, pop, peek), Overflow/Underflow kontrollerini, dizi ve bağlı liste implementasyonlarını, Call Stack ve Infix-to-Postfix uygulamalarını öğrenmektir.

8.1. Yığın Nedir? LIFO Prensibi ve Temel Operasyonlar

Yığın (Stack): Eleman ekleme ve çıkarma işlemlerinin yalnızca tepe (top) adı verilen tek bir uçtan yapıldığı, LIFO (Last In, First Out — Son Giren İlk Çıkar) prensibiyle çalışan doğrusal bir soyut veri yapısıdır. İlk eklenen eleman en altta kaldığından en son çıkarılır.

  • push(eleman): Yığının en üstüne yeni eleman ekler ($O(1)$). Dizi tabanlı yığında kapasite doluysa (top == kapasite - 1) Stack Overflow hatası oluşur.
  • pop(): Yığının en üstündeki elemanı çıkarır ve döndürür ($O(1)$). Yığın boşsa (top == -1 veya top == nullptr) Stack Underflow hatası oluşur.
  • peek() / top(): En üstteki elemanı yığından çıkarmadan görüntüler ($O(1)$).

8.3. Dizi ve Bağlı Liste ile Stack İmplementasyonu (C++)

Sabit boyutlu ve çok hızlı yığınlar için dizi (taşma riski vardır), boyut sınırı olmayan dinamik yığınlar için bağlı liste (her düğümde ekstra işaretçi alanı harcar) tercih edilir. Modern C++'ta hazır std::stack sınıfı da kullanılabilir.

A. Dizi ile Statik Stack

void push(int stack[], int& top, int eleman, int kapasite) {
    if (top == kapasite - 1) {
        cout << "Stack overflow!" << endl;
        return;
    }
    stack[++top] = eleman;
}

int pop(int stack[], int& top) {
    if (top == -1) {
        cout << "Stack underflow!" << endl;
        return -1;
    }
    return stack[top--];
}

int peek(int stack[], int top) {
    if (top == -1) {
        cout << "Stack is empty!" << endl;
        return -1;
    }
    return stack[top];
}

B. Bağlı Liste ile Dinamik Stack

struct Node {
    int data;
    Node* next;
};

void push(Node*& top, int eleman) {
    Node* yeni = new Node();
    yeni->data = eleman;
    yeni->next = top;       // Yeni düğüm eski tepeyi gösterir
    top = yeni;             // Tepe güncellenir (O(1))
}

int pop(Node*& top) {
    if (top == nullptr) {
        cout << "Stack underflow!" << endl;
        return -1;
    }
    int veri = top->data;
    Node* sil = top;
    top = top->next;
    delete sil;             // Bellek sızıntısını önlemek için serbest bırak
    return veri;
}

int peek(Node* top) {
    if (top == nullptr) {
        cout << "Stack is empty!" << endl;
        return -1;
    }
    return top->data;
}
Sınav İpucu: Dizi tabanlı yığında başlangıçta top = -1'dir. Eleman eklenirken önce artırılır (stack[++top]), çıkarılırken önce okunur sonra azaltılır (stack[top--]). Bağlı liste yığınında her new için pop ve temizlik sırasında mutlaka delete çağrılmalıdır.

9. Ünite: Kuyruk Veri Yapısı (Queue - FIFO)

Ünitenin Amacı: İlk Giren İlk Çıkar (FIFO) prensibiyle çalışan Kuyruk (Queue) veri yapısını, temel işlemlerini (enqueue, dequeue), doğrusal dizi kuyruğundaki sahte doluluk problemini ve modülo (%) aritmetikli Dairesel Kuyruk çözümünü, Deque ile Priority Queue türlerini ve bağlı liste implementasyonunu öğrenmektir.

9.1. Kuyruk Nedir? FIFO Prensibi ve Kullanım Alanları

Kuyruk (Queue): Ekleme işleminin arka uçtan (rear / tail), çıkarma işleminin ise ön uçtan (front / head) yapıldığı, FIFO (First In, First Out — İlk Giren İlk Çıkar) prensibiyle çalışan doğrusal veri yapısıdır.

  • enqueue(eleman): Kuyruğun sonuna (rear/tail) eleman ekler ($O(1)$). Dizi kapasitesi dolmuşsa Queue Overflow oluşur.
  • dequeue(): Kuyruğun başındaki (front/head) ilk eklenen elemanı çıkarır ve döndürür ($O(1)$). Kuyruk boşsa Queue Underflow oluşur.

9.2. Kuyruk Türleri: Doğrusal, Dairesel, Çift Uçlu (Deque) ve Öncelikli (Priority Queue)

  • Dairesel Kuyruk (Circular Queue): Doğrusal dizi kuyruğunda elemanlar çıkarıldıkça head/front sağa kayar ve dizinin ön kısmı boş kaldığı hâlde tail/rear == KAPASİTE - 1 olduğunda kuyruk dolu sanılır (Kuyruk Kayması / Sahte Doluluk). Dairesel kuyruk modülo aritmetiğiyle bu boş alanı yeniden değerlendirir.
  • Çift Uçlu Kuyruk (Deque - Double Ended Queue): Ekleme ve çıkarma işlemlerinin hem baştan hem sondan yapılabildiği esnek kuyruk türüdür (palindrom kontrolü, kayan pencere, iş çalma).
  • Öncelikli Kuyruk (Priority Queue): Her elemanın bir öncelik değeri vardır; geliştirilen kurala göre çıkarma işlemi geliş sırasına değil en yüksek öncelikli elemana göre yapılır (CPU scheduling, Dijkstra algoritması, acil servis triyajı).
Modülo (%) Aritmetiği ile Dairesel Kuyruk İndis Güncelleme Formülleri: $$\text{rear} = (\text{rear} + 1) \pmod{\text{KAPASİTE}}$$ $$\text{front} = (\text{front} + 1) \pmod{\text{KAPASİTE}}$$

9.3. Dizi, Dairesel Kuyruk ve Bağlı Liste İmplementasyonları (C++)

A. Dizi ile Doğrusal ve Dairesel Kuyruk

// Doğrusal Dizi Kuyruğu (head = 0, tail = -1)
void enqueue(int queue[], int& tail, int eleman, int kapasite) {
    if (tail == kapasite - 1) {
        cout << "Queue overflow!" << endl;
        return;
    }
    queue[++tail] = eleman;
}

int dequeue(int queue[], int& head, int tail) {
    if (head > tail) {
        cout << "Queue underflow!" << endl;
        return -1;
    }
    return queue[head++];
}

// Dairesel Kuyrukta Ekleme (front = -1, rear = -1 başlangıçlı)
void circularEnqueue(int dizi[], int& front, int& rear, int val, int KAPASITE) {
    if ((rear + 1) % KAPASITE == front) {
        cout << "Dairesel Kuyruk Dolu!" << endl;
        return;
    }
    if (front == -1) front = 0;
    rear = (rear + 1) % KAPASITE;
    dizi[rear] = val;
}

B. Bağlı Liste ile Dinamik Kuyruk (head ve tail)

struct Node {
    int data;
    Node* next;
};

void enqueue(Node*& head, Node*& tail, int eleman) {
    Node* yeni = new Node();
    yeni->data = eleman;
    yeni->next = nullptr;
    if (tail == nullptr) {          // Kuyruk boşsa head ve tail aynı düğümü gösterir
        head = tail = yeni;
    } else {
        tail->next = yeni;
        tail = yeni;
    }
}

int dequeue(Node*& head, Node*& tail) {
    if (head == nullptr) {
        cout << "Queue underflow!" << endl;
        return -1;
    }
    int veri = head->data;
    Node* sil = head;
    head = head->next;
    if (head == nullptr)            // Son eleman da çıkarıldıysa tail sıfırlanır!
        tail = nullptr;
    delete sil;
    return veri;
}
Sınav Notu: Bağlı liste kuyruğunda son eleman çıkarıldığında (head == nullptr olduğunda) tail = nullptr; yapılmazsa tail silinmiş bellek adresini gösteren bir dangling pointer hâline gelir. Modern C++ STL sınıfları: std::queue, std::deque, std::priority_queue.

10. Ünite: Özyineleme (Recursion) ve Çağrı Yığını Mimarisi

Ünitenin Amacı: Bir fonksiyonun kendini doğrudan veya dolaylı olarak çağırmasına dayanan Özyineleme (Recursion) tekniğini, Temel Durum (Base Case) ve Özyinelemeli Durum (Recursive Case) zorunluluğunu, Çağrı Yığınının (Call Stack) bellek davranışını, Faktöriyel ve Fibonacci (naive vs. iteratif/memoization) performans karşılaştırmasını öğrenmektir.

10.1. Özyineleme Nedir? Temel ve Özyinelemeli Durum

Özyineleme (Recursion): Bir fonksiyonun bir problemi daha küçük alt problemlere bölerek kendisini doğrudan veya dolaylı olarak çağırmasıdır. Her özyinelemeli fonksiyonun iki zorunlu parçası vardır:

  1. Temel Durum (Base Case): Özyinelemenin sona erdiği, fonksiyonun kendini çağırmadan doğrudan sonuç döndürdüğü durma koşuludur. Temel durum eksik veya hatalıysa fonksiyon sonsuz döngüye girer ve çağrı yığını dolarak Stack Overflow hatasıyla çöker.
  2. Özyinelemeli Durum (Recursive Case): Fonksiyonun problemi temel duruma yaklaştıracak biçimde küçülterek kendisini yeniden çağırdığı kısımdır.
Matematiksel Özyinelemeli Tanımlar: $$n! = \begin{cases} 1, & n = 0 \\ n \cdot (n-1)!, & n > 0 \end{cases} \qquad\qquad F(n) = \begin{cases} 0, & n = 0 \\ 1, & n = 1 \\ F(n-1) + F(n-2), & n \ge 2 \end{cases}$$

10.2. Avantajları, Dezavantajları ve Kullanım Alanları

  • Avantajları: Karmaşık ve kendini tekrar eden problemleri sadeleştirir, daha az ve okunaklı kod üretir, matematiksel tanımları ve hiyerarşik yapıları doğal olarak modeller.
  • Dezavantajları: Her çağrıda Call Stack'te yeni bir aktivasyon çerçevesi açıldığı için fazla bellek tüketir (derin özyinelemede Stack Overflow riski), fonksiyon çağrı maliyeti nedeniyle iterasyona göre daha yavaş olabilir ve hata ayıklaması zordur.

10.3. C++ Uygulamaları: Faktöriyel ve Fibonacci (Özyinelemeli vs. İteratif)

// 1. Özyinelemeli ve İteratif Faktöriyel - İkisi de O(n) zaman
int faktoriyel(int n) {
    if (n == 0) return 1;                   // Temel durum (Base case)
    return n * faktoriyel(n - 1);           // Özyinelemeli durum
}

int faktoriyelIteratif(int n) {
    int sonuc = 1;
    for (int i = 1; i <= n; i++) sonuc *= i;
    return sonuc;
}

// 2. Özyinelemeli Fibonacci - Naive O(2^n) zaman!
int fibonacci(int n) {
    if (n == 0) return 0;
    else if (n == 1) return 1;
    else return fibonacci(n - 1) + fibonacci(n - 2);
}

// 3. İteratif Fibonacci - O(n) zaman, O(1) bellek
int fibonacciIteratif(int n) {
    if (n == 0) return 0;
    if (n == 1) return 1;
    int a = 0, b = 1, c;
    for (int i = 2; i <= n; i++) {
        c = a + b;
        a = b;
        b = c;
    }
    return b;
}

11.1. Ağaç Nedir? Temel Terminoloji ve İkili Ağaç Kuralları

Ağaç (Tree): Düğümlerden (node) oluşan, döngü içermeyen (acyclic) hiyerarşik bir veri yapısıdır. Kök (root) düğüm hariç her düğümün tam olarak bir ebeveyni (parent) vardır. $N$ düğümlü her ağaçta (ve ikili ağaçta) tam olarak $N - 1$ kenar (dal) bulunur.

Kavram Tanım

Yaprak (Leaf)Alt düğümü (çocuğu) olmayan en alttaki uç düğümdür (derecesi 0).

Ebeveyn / Çocuk / KardeşBir düğümün doğrudan üstündeki ebeveyn, altındakiler çocuk, aynı ebeveyne bağlılar kardeştir (sibling).
Derinlik (Depth)Kökten ilgili düğüme kadar olan kenar sayısı (kökün derinliği 0'dır).

Özel Ağaç Özellikleri (Sınavlarda Sık Sorulur):
• İkili Ağaç (Binary Tree): Her düğümün en fazla 2 çocuğu (left ve right) olabilir; her düğüm 3 bileşen içerir (data, left, right).
• Tam İkili Ağaç (Full Binary Tree): Her düğüm 0 veya 2 çocuğa sahiptir. $L$ yaprağı olan tam ikili ağaçta toplam $2L - 1$ düğüm vardır (örneğin 8 yapraklı bir tam ikili ağaçta $2(8) - 1 = 15$ düğüm bulunur).
• Huffman / Trie Ağaçları: Karakterlere değişken uzunluklu ikili kodlar atamak (veri sıkıştırma) ve sözlük/otomatik tamamlama için kullanılır.

11.2. İkili Arama Ağacı (BST - Binary Search Tree)

İkili Arama Ağacı (BST): Her düğüm için; sol alt ağaçtaki tüm değerlerin düğümden küçük, sağ alt ağaçtaki tüm değerlerin düğümden büyük olduğu özel ikili ağaç türüdür.

BST Değişmez Kuralı: $$\forall x \in \text{SolAltAğaç}(\text{kök}):\; x < \text{kök.data} \qquad\text{ve}\qquad \forall y \in \text{SağAltAğaç}(\text{kök}):\; y > \text{kök.data}$$
  • Ekleme (Insert) ve Arama (Search): Kökten başlanır; değer mevcut düğümden küçükse sola, büyükse sağa ilerlenir.
  • Zaman Karmaşıklığı: Dengeli bir BST'de arama, ekleme ve silme ortalama $O(\log n)$'dir. Yüksekliği $h$ olan bir BST'de en derindeki elemanı aramak için en fazla $h + 1$ düğüm kontrol edilir.
  • Dengesizleşme Sorunu: Veriler sıralı eklenirse (örn: 10, 20, 30, 40...) ağaç tek taraflı bir bağlı listeye (çubuk) dönüşür ve karmaşıklık $O(n)$'e düşer. Bunu önlemek için AVL ve Red-Black Tree gibi kendiliğinden dengelenen ağaçlar kullanılır.
  • BST'de Silme'nin 3 Durumu: (1) Yaprak düğüm doğrudan silinir. (2) Tek çocuklu düğüm yerine kendi tek çocuğu bağlanır. (3) İki çocuklu düğüm yerine sol alt ağacın en büyüğü veya sağ alt ağacın en küçüğü (Inorder Successor) taşınır ve kopyalanan düğüm silinir.

11.3. C++ ile İkili Arama Ağacı (BST) Uygulaması

#include <iostream>
using namespace std;

struct Node {
    int data;
    Node* left;
    Node* right;
};

Node* yeniDugum(int veri) {
    Node* dugum = new Node();
    dugum->data = veri;
    dugum->left = dugum->right = nullptr;
    return dugum;
}

// BST'ye eleman ekleme
Node* ekle(Node* kok, int veri) {
    if (kok == nullptr)
        return yeniDugum(veri);
    if (veri < kok->data)
        kok->left = ekle(kok->left, veri);
    else if (veri > kok->data)
        kok->right = ekle(kok->right, veri);
    return kok;
}

// BST'de eleman arama - Ortalama O(log n), En kötü O(n)
Node* ara(Node* kok, int anahtar) {
    if (kok == nullptr || kok->data == anahtar)
        return kok;
    if (anahtar < kok->data)
        return ara(kok->left, anahtar);
    else
        return ara(kok->right, anahtar);
}

// Inorder gezinti (BST'de küçükten büyüğe sıralı çıktı verir)
void inorder(Node* kok) {
    if (kok != nullptr) {
        inorder(kok->left);
        cout << kok->data << " ";
        inorder(kok->right);
    }
}

// Postorder ile ağacı bellekten temizleme
void bellekTemizle(Node* kok) {
    if (kok != nullptr) {
        bellekTemizle(kok->left);
        bellekTemizle(kok->right);
        delete kok;
    }
}

12. Ünite: Ağaçlarda Gezinti Yöntemleri (Tree Traversal)

Ünitenin Amacı: İkili ağaçlardaki tüm düğümleri belirli bir sırayla ziyaret eden üç temel Derinlik Öncelikli Gezinti yöntemini (Preorder, Inorder, Postorder) ve Level-Order (BFS) gezintiyi, her birinin kullanım alanlarını, zaman ($O(n)$) ve alan ($O(\log n)$ / $O(n)$) karmaşıklıklarını, özyinelemeli ve yığın (stack) tabanlı iteratif C++ kodlarını öğrenmektir.

12.1. Üç Temel Gezinti Türü (DFS) ve Level-Order (BFS)

Ağaçta Gezinti (Traversal): Ağaçtaki her düğümün tam olarak bir kez, belirli bir düzene göre ziyaret edilmesidir. Kök düğümün ne zaman ziyaret edildiğine göre üç temel DFS yöntemi vardır:

  • 1. Preorder (Öncelikli — Kök, Sol, Sağ): Önce kök ziyaret edilir, sonra sol alt ağaç, en son sağ alt ağaç gezilir. Kullanım alanları: Ağacın kopyalanması (klonlama), ifade ağaçlarından Prefix (ön ek) gösterim üretme, dosya/dizin yapısını öncelikli gezme.
  • 2. Inorder (İçsel — Sol, Kök, Sağ): Önce sol alt ağaç, sonra kök, en son sağ alt ağaç gezilir. Kullanım alanları: BST'de verileri küçükten büyüğe sıralı elde etme, ifade ağaçlarından Infix (ara ek) gösterim üretme.
  • 3. Postorder (Sonradan — Sol, Sağ, Kök): Önce sol alt ağaç, sonra sağ alt ağaç, en son kök gezilir. Kullanım alanları: Düğüm silme ve belleği temizleme (çocuklar silinmeden ebeveyn silinmez), ifade ağaçlarından Postfix (son ek) gösterim üretme, alt klasörleri önce silme.
  • 4. Level-Order (Seviye Seviye — BFS): Ağacı kökten başlayarak seviye seviye, soldan sağa doğru bir Kuyruk (Queue) yardımıyla gezer.

12.3. C++ Uygulaması: Özyinelemeli ve Yığın (Stack) ile İteratif Gezinti

Çok derin veya dengesiz ağaçlarda özyinelemenin yol açabileceği Stack Overflow riskinden kaçınmak için std::stack kullanarak iteratif gezinti uygulanabilir:

#include <iostream>
#include <stack>
using namespace std;

struct Node {
    int data;
    Node* left;
    Node* right;
};

void preorder(Node* root) {
    if (root != nullptr) {
        cout << root->data << " ";  // 1. Kök
        preorder(root->left);       // 2. Sol
        preorder(root->right);      // 3. Sağ
    }
}

void inorder(Node* root) {
    if (root != nullptr) {
        inorder(root->left);        // 1. Sol
        cout << root->data << " ";  // 2. Kök
        inorder(root->right);       // 3. Sağ
    }
}

void postorder(Node* root) {
    if (root != nullptr) {
        postorder(root->left);      // 1. Sol
        postorder(root->right);     // 2. Sağ
        cout << root->data << " ";  // 3. Kök
    }
}

// Stack kullanarak İteratif Inorder Gezinti
void inorderIterative(Node* root) {
    stack<Node*> s;
    Node* curr = root;
    while (curr != nullptr || !s.empty()) {
        while (curr != nullptr) {
            s.push(curr);
            curr = curr->left;      // En sola kadar in
        }
        curr = s.top();
        s.pop();
        cout << curr->data << " ";  // Kökü yazdır
        curr = curr->right;         // Sağ alt ağaca geç
    }
}
Sınav Notları:
• İteratif derinlik öncelikli gezintide yardımcı veri yapısı olarak Yığın (Stack), seviye seviye (Level-Order / BFS) gezintide ise Kuyruk (Queue) kullanılır.
• Ağacı bellekten tamamen silmek için en uygun gezinti yöntemi Postorder'dır (önce alt düğümler, en son kök silinir).

13. Ünite: Sıralama Algoritmaları I (Bubble, Selection, Insertion Sort)

Ünitenin Amacı: Sıralama (sorting) kavramını, kararlılık (stability) ve yerinde çalışma (in-place) ölçütlerini, üç temel karşılaştırmalı sıralama algoritması olan Bubble Sort, Selection Sort ve Insertion Sort'un adım adım çalışma mantığını, zaman/alan karmaşıklıklarını ve C++ implementasyonlarını öğrenmektir.

13.1. Sıralama Nedir? Temel Sınıflandırma Kriterleri

Sıralama (Sorting): Bir veri kümesindeki elemanların belirli bir düzene (genellikle artan veya azalan) göre yeniden düzenlenmesidir. Sıralı veri üzerinde ikili arama (Binary Search) $O(\log n)$ sürede yapılabilir ve istatistiksel analiz/raporlama kolaylaşır.

  • Kararlı (Stable): Sıralama öncesinde aynı anahtara (değere) sahip elemanların göreli sırası sıralama sonrasında da korunur. Örneğin (5,7), (3,6), (1,9), (9,1), (1,3) çiftleri ilk elemana göre kararlı sıralanırsa (1,9), (1,3)'ten önce kalır.
  • Yerinde (In-place): Sıralama için dizi boyutuna bağlı büyük ek bellek kullanmaz, yalnızca $O(1)$ ek bellek harcar.

13.2. Bubble Sort, Selection Sort ve Insertion Sort

1. Kabarcık Sıralama (Bubble Sort)

Bitişik (komşu) elemanları karşılaştırır ve yanlış sıradaysa takas (swap) eder. Her geçişte en büyük eleman sona "kabarcık" gibi taşınır. swapped bayrağı kullanılırsa, zaten sıralı bir dizide ilk geçişte takas olmadığı için erken çıkış yapar ve en iyi durumda $O(n)$ sürede biter. Kararlı ve yerindedir.

Bubble Sort Adımları — [5, 2, 9, 1, 5]:
• 1. Geçiş: [2, 5, 1, 5, 9] (en büyük 9 sona oturdu)
• 2. Geçiş: [2, 1, 5, 5, 9]
• 3. Geçiş: [1, 2, 5, 5, 9] → 4. geçişte takas olmaz, erken çıkış!

2. Seçmeli Sıralama (Selection Sort)

Her adımda sıralanmamış kalan kısmın en küçük elemanını bulur ve sıralanmamış kısmın başındaki elemanla yer değiştirir. En iyi, ortalama ve en kötü durumda daima $O(n^2)$ karmaşıklığa sahiptir (erken çıkış yoktur). $n$ elemanlı bir dizide en fazla $n - 1$ takas yapar. Yerindedir ancak uzun mesafeli takaslar nedeniyle genellikle kararlı değildir.

Selection Sort Adımları — [5, 2, 9, 1, 5]:
• 1. Adım (en küçük 1 ↔ 5): [1, 2, 9, 5, 5]
• 2. Adım (en küçük 2 yerinde): [1, 2, 9, 5, 5]
• 3. Adım (en küçük 5 ↔ 9): [1, 2, 5, 9, 5]
• 4. Adım (en küçük 5 ↔ 9): [1, 2, 5, 5, 9]

3. Eklemeli Sıralama (Insertion Sort)

Diziyi sıralı (sol) ve sırasız (sağ) iki parçaya ayırır; sırasız kısımdan aldığı her elemanı (key), sol taraftaki sıralı kısımda kendisinden büyük elemanları sağa kaydırarak uygun konumuna ekler (iskambil kartlarını dizmeye benzer). En iyi durumda (sıralı veya neredeyse sıralı dizide) $O(n)$, ortalama/en kötü durumda $O(n^2)$ çalışır. Kararlı ve yerindedir; küçük veri setlerinde çok etkilidir.

Insertion Sort Adımları — [5, 2, 9, 1, 5]:
• 1. Adım (2, 5'in önüne): [2, 5, 9, 1, 5]
• 2. Adım (9 yerinde): [2, 5, 9, 1, 5]
• 3. Adım (1 en başa): [1, 2, 5, 9, 5]
• 4. Adım (5, 9'un önüne): [1, 2, 5, 5, 9]

13.3. C++ Uygulamaları

#include <iostream>
#include <algorithm>
using namespace std;

void bubbleSort(int dizi[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;
        for (int j = 0; j < n - i - 1; j++) {
            if (dizi[j] > dizi[j + 1]) {
                swap(dizi[j], dizi[j + 1]);
                swapped = true;
            }
        }
        if (!swapped) break;        // Erken çıkış -> sıralı dizide O(n)
    }
}

void selectionSort(int dizi[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int min_idx = i;
        for (int j = i + 1; j < n; j++)
            if (dizi[j] < dizi[min_idx])
                min_idx = j;
        swap(dizi[i], dizi[min_idx]);
    }
}

void insertionSort(int dizi[], int n) {
    for (int i = 1; i < n; i++) {
        int key = dizi[i];
        int j = i - 1;
        while (j >= 0 && dizi[j] > key) {
            dizi[j + 1] = dizi[j];
            j--;
        }
        dizi[j + 1] = key;
    }
}
Sınav İpucu: Üç temel $O(n^2)$ algoritma arasında Bubble Sort ve Insertion Sort kararlıdır (stable) ve sıralı dizide $O(n)$ çalışır; Selection Sort ise dizi sıralı olsa bile tüm kalan elemanları taradığı için her durumda $O(n^2)$'dir ve genellikle kararlı değildir. Büyük veri setlerinde C++ STL'deki std::sort (Introsort) tercih edilir.

14. Ünite: Sıralama Algoritmalarının Karşılaştırılması (Merge Sort, Quick Sort)

Ünitenin Amacı: Böl ve Yönet (Divide and Conquer) stratejisiyle çalışan gelişmiş Merge Sort ve Quick Sort algoritmalarının çalışma mekanizmalarını ve C++ kodlarını kavramak; Bubble, Selection, Insertion, Merge, Quick ve Heap Sort algoritmalarını zaman, bellek, kararlılık ve yerinde çalışma ölçütlerine göre karşılaştırarak doğru senaryo seçimini yapmaktır.

14.1. Karmaşık Sıralama Algoritmaları: Merge Sort, Quick Sort ve Heap Sort

1. Birleştirmeli Sıralama (Merge Sort)

Böl ve Yönet (Divide and Conquer) yaklaşımını kullanır: Dizi tek eleman kalana dek sürekli ikiye bölünür, ardından sıralı alt diziler karşılaştırılarak birleştirilir (merge). En iyi, ortalama ve en kötü durumda daima $O(n \log n)$ zaman karmaşıklığı garantiler. Kararlıdır (stable) ve büyük veri setleriyle harici (diskte) sıralama için idealdir; ancak birleştirme için $O(n)$ ek bellek gerektirdiğinden in-place değildir.

2. Hızlı Sıralama (Quick Sort)

Diziden bir pivot eleman seçilir; partition işlemiyle pivot'tan küçük elemanlar sola, büyük elemanlar sağa yerleştirilir ve alt diziler özyinelemeli olarak sıralanır. Ortalama durumda $O(n \log n)$ hızla pratikte en hızlı algoritmalardandır ve yerinde (in-place) çalışır (özyineleme derinliği için ortalama $O(\log n)$ yığın belleği kullanır). Ancak kötü pivot seçilirse (ör. zaten sıralı dizide uç eleman pivot seçilirse) en kötü durumda $O(n^2)$ olur; kararlı değildir. Bunu önlemek için rastgele pivot veya median-of-three önerilir.

3. Yığın Sıralaması (Heap Sort)

Temelinde Öncelikli Kuyruk (Priority Queue / Binary Heap) yapısı kullanarak Selection Sort mantığını hızlandıran algoritmadır. Ekstra dizi kullanmadan ($O(1)$ bellek, in-place) en iyi, ortalama ve en kötü durumda $O(n \log n)$ performans sunar; kestirilebilir çalışma süresi nedeniyle gerçek zamanlı sistemlerde tercih edilir, fakat kararlı değildir.

14.2. C++ Uygulamaları: Merge Sort ve Quick Sort

// 1. MERGE SORT (Böl ve Birleştir)
void merge(int dizi[], int sol, int orta, int sag) {
    int n1 = orta - sol + 1;
    int n2 = sag - orta;
    int* L = new int[n1];
    int* R = new int[n2];
    for (int i = 0; i < n1; i++) L[i] = dizi[sol + i];
    for (int j = 0; j < n2; j++) R[j] = dizi[orta + 1 + j];

    int i = 0, j = 0, k = sol;
    while (i < n1 && j < n2) {
        if (L[i] <= R[j]) dizi[k++] = L[i++];
        else              dizi[k++] = R[j++];
    }
    while (i < n1) dizi[k++] = L[i++];
    while (j < n2) dizi[k++] = R[j++];
    delete[] L;
    delete[] R;
}

void mergeSort(int dizi[], int sol, int sag) {
    if (sol < sag) {
        int orta = sol + (sag - sol) / 2;
        mergeSort(dizi, sol, orta);
        mergeSort(dizi, orta + 1, sag);
        merge(dizi, sol, orta, sag);
    }
}

// 2. QUICK SORT (Pivot ve Partition)
int partition(int dizi[], int low, int high) {
    int pivot = dizi[high];
    int i = low - 1;
    for (int j = low; j < high; j++) {
        if (dizi[j] < pivot) {
            i++;
            swap(dizi[i], dizi[j]);
        }
    }
    swap(dizi[i + 1], dizi[high]);
    return i + 1;
}

void quickSort(int dizi[], int low, int high) {
    if (low < high) {
        int pi = partition(dizi, low, high);
        quickSort(dizi, low, pi - 1);
        quickSort(dizi, pi + 1, high);
    }
}
